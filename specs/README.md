# RPay Improvement Proposals (RIPs)

**Status:** Proposed governance process; not an established standards body.

RIPs are design documents for significant changes to RPay's message exchange, compatibility rules, security assumptions, transport framing or relay behavior.

## Suggested lifecycle

**Draft → Review → Accepted → Implemented → Superseded/Withdrawn**

Acceptance should require a clear motivation, normative specification, compatibility impact, security analysis, test vectors and implementation evidence. A draft's existence does not imply consensus or deployment.

## Suggested RIP format

```markdown
# RIP-XXXX: Short title

- Status: Draft
- Author(s):
- Created:
- Type: Core | Transport | Security | Informational

## Abstract
## Motivation
## Specification
## Backward compatibility
## Security considerations
## Test vectors
## Reference implementation
## Alternatives considered
```

Do not assign official RIP numbers until maintainers adopt a numbering policy. Proposals may be discussed in GitHub issues or pull requests.
